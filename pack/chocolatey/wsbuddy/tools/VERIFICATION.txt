Verification is intended to assist the Chocolatey moderators and community
in verifying that this package's contents are trustworthy.

1. Download the official release assets from:
   https://github.com/kilrkrow/win-service-buddy/releases/tag/v0.2.1

   - wsbuddy-cli-win-x64-v0.2.1.zip
   - wsbuddy-app-win-x64-v0.2.1.zip

2. Obtain the SHA256 checksum of each file, for example:

   Get-FileHash .\wsbuddy-cli-win-x64-v0.2.1.zip -Algorithm SHA256
   Get-FileHash .\wsbuddy-app-win-x64-v0.2.1.zip -Algorithm SHA256

3. Compare to the values used in tools\chocolateyinstall.ps1:

   CLI: <stamped by build/choco-pack.ps1>
   APP: <stamped by build/choco-pack.ps1>

The package does not embed the binaries; it downloads them from GitHub Releases at install time.

The release assets are reproduced from source with scripts/publish.ps1 in the
project repository, which publishes both self-contained win-x64 payloads and
prints the SHA256 of each ZIP.
